# Mi actividad digital según la hora

Web de investigación sobre cómo se distribuye la actividad digital de Jana a lo largo del día, a partir de sus registros de Tiempo de uso del iPhone del 20 de octubre al 3 de noviembre de 2026.

## Web

GitHub Pages publica esta web desde `index.html`. Los archivos `style.css` y `script.js` contienen los estilos y las interacciones. Las imágenes de los referentes están en la raíz y se enlazan con rutas relativas.

## Documentación del proyecto

- `personalidad.md`, `contexto.md`, `criterio.md` y `log.md` documentan la colaboración y las decisiones.
- `fichas/` contiene una ficha por cada sección de scroll.
